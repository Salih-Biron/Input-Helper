# 使用说明与故障排查

## 选择输入模式

**代码模式**适用于会自动缩进的代码编辑器。第一行直接输入；后续每行先发送 `Esc` 关闭自动补全，再回车、等待编辑器响应，通过 `Shift + Home` 选中当前行光标之前的内容，最后输入原始整行。空行通过临时空格和一次退格清除自动缩进。

这套机制假定回车已经成功换行。若目标编辑器拦截回车或重新定义行首选择，结果可能不正确。建议使用空白测试文件，并从行首开始输入。

**普通文本模式**适用于普通文本框，不执行自动缩进覆盖。输入多行文本时仍会发送回车，因此目标页面自身的回车行为也会影响结果。

## 文件编码与文本预处理

“导入 TXT”先按 UTF-8 读取，解码失败时尝试 GBK。“保存内容”使用 UTF-8。其他编码请先在文本编辑器中转换为 UTF-8。

“预处理缩进”会执行：

1. 将 Windows 和旧式 Mac 换行统一为 `\n`。
2. 删除文本中的 BOM 字符 `U+FEFF`。
3. 将不换行空格 `U+00A0` 替换为普通空格。
4. 开启“Tab 转空格”时，按设置的制表位展开 Tab。

预处理不会分析语法，也不会自动修复原始代码的缩进。上述替换作用于整个文本，字符串中的特殊空白同样可能改变。正式输入前请检查处理结果。

## 启动与停止

准备好文本后，可点击“3秒后开始”，再在倒计时内切换到目标编辑器；也可提前切到目标编辑器，使用 `Ctrl + Shift + Q` 启动。

程序发送按键时不锁定目标窗口。输入过程中切换焦点，后续内容会进入新的活动窗口。需要中止时，按下 `Ctrl + Shift + X`，也可使用助手窗口的“停止当前输入”按钮。停止热键在倒计时和实际输入期间持续监听，直接设置线程停止标记；倒计时、字符间隔和换行等待都可被打断，零间隔输入也在字符之间检查停止状态。已经送入系统的按键无法撤回。

## 本地配置

源码运行时，程序从 `app.py` 同目录下的 `config.json` 读取设置，并在预处理、导入、保存、清空或关闭窗口时写入配置。首次运行可以不创建该文件，程序会采用内置默认值。

如需预置配置，可在项目根目录执行：

```powershell
Copy-Item config.example.json config.json
```

已有 `config.json` 时，请先备份或直接编辑，避免覆盖原设置。

| 字段 | 含义 |
| --- | --- |
| `start_delay` | 开始前延迟，单位：秒 |
| `char_interval` | 每字间隔，单位：秒 |
| `tab_size` | Tab 展开的制表位宽度 |
| `expand_tabs` | 是否将 Tab 转为空格 |
| `code_mode` | 是否使用代码模式 |
| `cached_text` | 下次启动时恢复的待输入文本 |

EXE 将配置保存到 `%LOCALAPPDATA%\InputHelper\config.json`，例如当前用户目录下的 `AppData\Local\InputHelper\config.json`。若 `LOCALAPPDATA` 未设置，则使用当前用户主目录下的 `AppData\Local\InputHelper\config.json`。配置目录不存在时自动创建，保存时先写同目录临时文件，再原子替换旧配置。

配置以本地明文保存，包含待输入内容。源码版与 EXE 版使用不同位置，不会自动迁移。需要迁移时，先正常退出程序，再将原配置复制到目标位置；此前旧版单文件 EXE 的临时配置若已被清理，无法恢复。配置在预处理、导入、保存、清空或正常关闭窗口时写入；强制结束进程可能丢失尚未保存的修改。

## 常见问题

| 现象 | 检查与处理 |
| --- | --- |
| 文字进入了错误窗口 | 使用倒计时启动，并在开始前确认目标编辑区域已获得焦点 |
| 缩进不断增加 | 开启代码模式和 Tab 转空格，使 Tab 宽度与编辑器一致；检查原文缩进 |
| 回车后多出 `auto` 等文字，随后一行消失 | 确认正在运行包含“回车前发送 Esc”修复的版本；若仍发生，关闭目标编辑器的自动补全后，用短文本复测 |
| 自动生成 `*`、括号或多余的行 | 检查自动注释续行、括号补全和多光标设置；这些行为尚未被完整补偿 |
| 字符丢失或顺序异常 | 将每字间隔提高到 `0.05` 秒或更长，确认网页响应正常 |
| 停止热键不起作用 | 确认热键注册成功、没有其他程序占用组合键，并使用新版程序；可用窗口停止按钮中止 |
| 中文显示异常 | 将输入文件转换为 UTF-8，检查输入法是否拦截字符 |
| 双击启动脚本报环境不存在 | 按 README 创建 `.venv` 并安装运行依赖 |
| 源码启动提示缺少 Tkinter | 使用包含 Tcl/Tk 的 Python 发行版，重新创建环境；Tkinter 通常不通过 pip 单独安装 |

仍无法解决时，请按 [反馈指南](../CONTRIBUTING.md) 提供最短复现文本、设置和实际输出。

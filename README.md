# Input Helper · 自动输入助手

面向 Windows 的桌面自动输入工具，使用 Python、Tkinter 和 Windows `SendInput` 接口，将预先准备的文本输入到当前获得焦点的编辑区域。

项目提供逐字输入、TXT 文件导入、输入速度控制，以及针对网页代码编辑器的自动缩进补偿。代码模式围绕 Educoder 使用场景开发，适用于需要保留原始缩进的多行文本输入。

## 功能

- **文本输入**：支持中文及其他 Unicode 字符，可设置开始前延迟和每字间隔。
- **代码模式**：逐行输入，换行后选中编辑器生成的行首内容，再用原始整行覆盖，减少自动缩进叠加。
- **自动补全处理**：代码模式每次换行前发送 `Esc`，关闭可能拦截回车的候选框。
- **文本预处理**：统一换行符、清除 BOM、将不换行空格转换为普通空格，并可按指定宽度将 Tab 转为空格。
- **文件与配置**：导入 UTF-8 或 GBK 文本、保存 UTF-8 文本，源码运行时将设置和待输入内容保存在本地 `config.json`。
- **输入控制**：提供全局开始热键、倒计时启动和窗口停止按钮。

## 环境要求

| 项目 | 要求或说明 |
| --- | --- |
| 操作系统 | Windows；实际输入依赖 Windows API |
| Python | 推荐 3.12；项目现有本地验证环境为 CPython 3.12.13 / Windows 11 |
| 环境管理 | [uv](https://docs.astral.sh/uv/) |
| 图形界面 | Python 自带的 Tkinter / Tcl / Tk |
| 运行依赖 | `keyboard`，详见 [requirements.txt](requirements.txt) |

其他操作系统不支持实际自动输入。不同网页编辑器、快捷键映射和输入法可能影响结果，建议先在空白测试文件中输入短文本。

## 快速开始

在 Windows PowerShell 中执行：

```powershell
git clone https://github.com/Salih-Biron/Input-Helper.git
cd Input-Helper
uv venv --python 3.12
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

完成环境安装后，也可以双击根目录下的 `launch_input_helper.bat` 启动。启动脚本使用项目内的 `.venv`，无需预先激活环境。

### 输入文本

1. 在助手中粘贴文本，或点击“导入 TXT”选择文件；可使用 [示例代码](examples/python_sample.txt) 试用。
2. 输入代码时，开启“代码模式(自动缩进补偿)”和“Tab 转空格”，Tab 宽度设为 `4`。
3. 点击“预处理缩进”，检查助手中的文本是否符合预期。
4. 点击“3秒后开始”，在倒计时内切换到目标编辑器，并将光标放到空白行的行首。
5. 等待输入结束，再检查目标编辑器中的内容。

“3秒后开始”至少等待 3 秒；若设置的开始前延迟更长，则采用较长的时间。输入时不要切换窗口或移动光标，程序始终向当前获得焦点的区域发送按键。

### 建议参数

| 设置 | 建议值 |
| --- | --- |
| 代码模式 | 网页代码编辑器开启；普通文本框可关闭 |
| Tab 转空格 | 开启 |
| Tab 宽度 | `4`，并与目标编辑器保持一致 |
| 每字间隔 | 从 `0.03`～`0.05` 秒开始，卡顿时适当增大 |
| 启动方式 | 首次使用优先选择“3秒后开始” |

## 快捷键与停止方式

| 操作 | 方式 | 当前行为 |
| --- | --- | --- |
| 开始输入 | `Ctrl + Shift + Q` | 在助手运行且空闲时触发，随后按设置延迟开始 |
| 停止输入 | 窗口中的“停止当前输入” | 设置停止标记，在后续输入检查点停止 |
| 停止热键 | `Ctrl + Shift + X` | 已注册，但当前实现会在发送文字期间暂停热键监听，不能依赖它中断输入 |

## 兼容性与已知限制

- 代码模式依赖目标编辑器正确处理 `Esc`、`Enter` 和 `Shift + Home`。程序不读取目标编辑器状态，无法确认回车是否真正换行，也无法校验最终文本。
- 多光标、自动注释续行、括号补全、自定义快捷键和输入法候选框可能影响输入。出现异常时先用窗口停止按钮中止，再检查目标编辑器设置。
- 文本预处理会改变 Tab、不换行空格和 BOM，包括字符串中的这些字符。需要逐字符保留特殊空白时，应先核对预处理结果。
- 配置中包含 `cached_text`（待输入文本）。个人 `config.json` 已被 Git 忽略，请勿手动提交含敏感内容的配置。
- 单文件 EXE 的配置路径当前位于 PyInstaller 解包目录，跨次启动持久保存配置尚无保证；需要稳定保存配置时建议从源码运行。
- 现有自动化测试模拟缩进与自动补全行为，不代表已完成所有浏览器、网站或语言的兼容性测试。
